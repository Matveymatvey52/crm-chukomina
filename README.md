# CRM Екатерины Чукоминой — прототип

Риелтор, новостройки Москвы и области. Прототип CRM: заявки по этапам, карточка клиента, ролики и кодовые слова, гайды, статистика.
Клиенты и цифры в демо-данных выдуманы.

Сайт: https://matveymatvey52.github.io/crm-chukomina/

## Как устроено
- `index.html`, `app.css` — страница и оформление (цвета и шрифты как на сайте Екатерины).
- `js/store.js` — хранилище. Сейчас данные в браузере устройства (localStorage, PDF — в IndexedDB). **При переносе на сервер меняется только этот файл.**
- `js/core.js` — состояние и действия, `js/ui.js` — экраны, `js/demo.js` — демо-данные, `js/zhk.js` — ЖК с сайта.
- `tools/test.js` — автотест в WebKit (движок Safari): `node tools/test.js`.
- `./publish.sh "что изменилось"` — тест, коммит, выкладка.
